# LUMINA

Mais que uma Bíblia, uma jornada com Deus.

App web para celular: leitura da Bíblia completa, "Como está seu coração hoje?", planos de leitura, anotações, diário de oração, favoritos, cartões para os Stories e modo noturno. Instala na tela inicial do celular (iPhone e Android) sem loja de apps e funciona sem internet depois da primeira visita.

- Texto bíblico: João Ferreira de Almeida (domínio público), via [bible-api.com](https://bible-api.com).
- Fotos: [Unsplash](https://unsplash.com) (licença Unsplash).
- Os dados de cada pessoa (anotações, orações, favoritos) ficam só no aparelho dela.

## Como atualizar
Ao mudar qualquer arquivo, aumente a versão em `sw.js` (`lumina-v1` → `lumina-v2`) para os celulares receberem a atualização.
